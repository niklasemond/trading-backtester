About this application

This application tests a declarative trading strategy against historical daily market data. The current strategy buys when a fast simple moving average crosses above a slow simple moving average and exits when it crosses below. Signals are generated using each day's close and, by design, cannot execute until the next available bar's open.

Why this matters: the separation between signal time and execution time is intended to prevent look-ahead bias. Pre-start history may warm up indicators, but it cannot create portfolio activity before your selected start date.

Inputs you can change

Symbol

The equity or ETF to test. The first milestone is designed around US-listed instruments such as SPY.

Fast & slow SMA

The moving-average windows. Smaller fast windows react more quickly; the slow SMA represents the longer trend.

Date range

Controls the experiment period. Additional earlier data is fetched only to warm up indicators.

Starting capital

The cash balance at the beginning of the selected experiment period. All return metrics use this as the starting base.

Commission

A fixed cost charged whenever an order is executed. Higher commissions penalize strategies that trade frequently.

Slippage

An adverse price adjustment in basis points. Buys execute slightly higher and sells slightly lower than the observed open.

Cash buffer

The fraction of capital deliberately left in cash rather than deployed into the position.

Fractional shares

When enabled, sizing may use partial shares; otherwise the engine buys the largest affordable whole-share quantity.

Provider

The source of historical market data. Yahoo Finance is currently the built-in free research provider.

Strategy filters

Optional price-trend, momentum, and volatility rules use StrategySpec 1.1. Entry and exit groups can use AND or OR logic.

How to read the results

Total return

The cumulative percentage gain or loss from starting capital to final portfolio value.

CAGR

The annualized compounded return over the actual elapsed calendar period.

Volatility

Annualized variability of daily returns. Lower volatility means a smoother return path, not necessarily a better strategy.

Sharpe ratio

Return per unit of daily volatility, annualized using a 0% risk-free rate in the current milestone.

Maximum drawdown

The worst peak-to-trough loss during the experiment. Smaller drawdowns generally indicate less severe historical loss episodes.

Trades

The number of completed strategy round trips. The trade table shows every executed buy and sell fill.

Buy-and-hold is shown as the traditional baseline: it buys at the first in-range open using the same cost and sizing assumptions, then holds through the final close.
